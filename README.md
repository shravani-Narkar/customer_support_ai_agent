# AI Support Issue Analysis Agent

This project is an AI-powered support issue analysis system built for all hackathon use cases as mentioned.

## Features

- Upload and analyze CSV datasets
- Perform automated EDA (Exploratory Data Analysis)
- Detect issue patterns and trends
- AI-powered query answering based on dataset insights

## Tech Stack

- Python
- Pandas
- Groq API
- LLM-based contextual analysis

## How to Run

```bash
pip install pandas numpy python-dotenv groq
